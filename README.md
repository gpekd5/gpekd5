**담당 역할**
- 팀장으로 프로젝트 일정 관리 및 역할 조율
- QueryDSL 기반 상품 동적 검색 및 관심상품 기능 개발
- Caffeine 및 Redis 캐싱 성능 검증

**주요 성과**

- 검색 Cache Hit 99% 이상 확인
- Presigned PUT URL을 활용해 이미지 업로드 트래픽을 서버에서 S3로 분리
